# `@ethio-pay/telebirr`

[![npm version](https://img.shields.io/npm/v/@ethio-pay/telebirr.svg)](https://www.npmjs.com/package/@ethio-pay/telebirr)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> Telebirr (Ethio Telecom Fabric / H5) payment provider adapter implementation for `@ethio-pay/core`.

## Installation

```bash
npm install @ethio-pay/core @ethio-pay/telebirr
# or using the umbrella package:
npm install ethio-pay
```

## Features

- Telebirr H5 / Web checkout session creation.
- RSA SHA256 signature signing and verification.
- Webhook callback verification and notification parsing.
- Query transaction status.
